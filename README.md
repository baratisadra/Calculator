# Calculator

## Overview

A calculator built using HTML, CSS, and JavaScript. It has a pink and black theme and supports input through buttons or a keyboard.

## Features

- Addition, subtraction, multiplication, and division
- Decimal calculations
- DEL button to delete the last character
- AC button to clear the calculation
- Keyboard controls
- Responsive layout

## Languages

- HTML
- CSS
- JavaScript

## Running the Project

Download both files into the same folder and open `index.html` in a browser. No installation is required.

## Future Improvements

- Calculation history
- Percentage calculations
- Light and dark theme options
